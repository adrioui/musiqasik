## 2024-05-22 - Graph Interaction Performance **Learning:** Hover interactions on force-directed graphs are extremely performance-sensitive. Iterating over all edges (O(E)) to find neighbors on every `mouseenter` event causes noticeable jank when edge count is high (hundreds/thousands). **Action:** Pre-calculate adjacency lists/maps (O(E) once) and use O(1) lookups in event handlers. Memoize the adjacency structure to avoid rebuilding it on every render, only when graph topology changes.
