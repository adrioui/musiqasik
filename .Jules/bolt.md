## 2026-02-02 - Missing Debounce on Window Resize **Learning:** Critical resize listeners, like those used for D3 graph dimensions, were attached directly to the `resize` event without debouncing. This caused excessive re-renders (looping the layout calculation) during browser resizing, leading to significant jank and state resets in the `ForceGraph`. **Action:** Always wrap `window` resize listeners in a `debounce` function (e.g., 200ms) when they trigger state updates or expensive computations.
