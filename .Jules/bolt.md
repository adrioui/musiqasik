## 2025-02-10 - Graph Verification Mocks **Learning:** When verifying D3 force graphs that build data recursively (BFS traversal of API results), simple mocks for the initial node are insufficient. The mock must handle the specific recursive calls (e.g., `artist.getinfo` for neighbors discovered via `artist.getsimilar`) with correct data structures, otherwise nodes won't render and selectors will time out. **Action:** Trace the full data loading pipeline (Service -> Hook -> Component) before writing mocks for complex visualizations to ensure all required data points (like artist info for neighbors) are provided.
