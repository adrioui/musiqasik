## 2025-02-13 - [Debounce Resize Listeners] **Learning:** Attaching resize listeners directly to state setters in React hooks (like `useElementDimensions`) causes excessive re-renders (one per pixel change), leading to layout thrashing. **Action:** Always wrap resize handlers in a `debounce` function (e.g., 200ms) and ensure the debounced function is cancelled in the cleanup phase to prevent memory leaks and performance degradation.
