## 2025-05-18 - Vitest JSDOM Compatibility **Learning:** The current environment has a compatibility issue between Vitest and JSDOM, causing `TypeError: The "context" argument must be of type object` when using `renderHook`. **Action:** When testing React hooks that don't strictly require DOM, extract the logic into pure functions and test them with `// @vitest-environment node` to bypass JSDOM.
